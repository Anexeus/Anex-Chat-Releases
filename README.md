# Anex Chat for Android

Official Android downloads and release notes from Anexeus.

## Download and install

Open [Releases](https://github.com/Anexeus/Anex-Chat-Releases/releases) and select a published build for an ARM64 Android phone. When a release is available, **Anex-Chat.apk** is the compact installer. If a release includes **Anex-Chat-Storage.zip**, extract the APK inside it for the smaller installed footprint. Both editions use the same signing identity.

Open the APK and tap **Install** or **Update**. To preserve chats, install signed updates over your existing Anex release. Back up chats before replacing an installation with a different signature.

## Help and privacy

- **Updates:** Android periodically checks this repository for stable releases. Android asks you to confirm installation.
- **Incoming calls:** In the app, open **You → Settings → Audio & video calls → Incoming call ringtone**.
- **Terms and privacy:** Read the [Anex Chat terms and privacy information](TERMS.md).
- **Support and source access:** Recipients can request the matching source through [Issues](https://github.com/Anexeus/Anex-Chat-Releases/issues). Keep invite links, backups, personal details and keys out of public issues.

Anex Chat is based on SimpleX Chat and distributed under AGPL-3.0.
